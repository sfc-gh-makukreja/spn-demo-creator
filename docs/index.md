# CoWork Demo Creator

`spn-demo-creator` is a Cortex Code skill that builds a complete Snowflake CoWork demo for you:

- synthetic data with a story built into it
- a semantic view for structured questions
- a Cortex Search service for documents
- a Cortex Agent that uses both
- six demo questions and a timed demo script

It works in two modes:

| Mode | Use it when |
|---|---|
| **Industry** | You have no named customer yet, or you are running a workshop. The skill researches the industry and proposes three use cases. |
| **Customer** | You have a named customer. The skill researches the company and tailors the use cases. |

## The demo story

Every demo follows the same three acts, so it lands in about ten minutes.

1. **What happened:** a headline number with a clear split.
2. **Rule out the obvious:** the thing everyone suspects turns out not to matter.
3. **Find the real drivers:** the agent finds the hidden patterns, backs them with documents, and recommends what to do.
